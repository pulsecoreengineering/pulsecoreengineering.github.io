// about

PulseCore Engineering makes open-source C++ libraries for embedded systems — built around one principle: firmware deserves the same quality of tooling that application software takes for granted.

Every library ships with a clear contract, predictable resource use, and no hidden costs. No heap. No runtime surprises. Just code that does exactly what it says, on whatever hardware you're running.

  • No dynamic allocation — static by design
  • Predictable resource use — known at compile time
  • No RTTI, no exceptions, no overhead you didn't ask for
  • Works across AVR, ARM Cortex-M, RISC-V and beyond
  • Compatible with Arduino, PlatformIO, and bare-metal toolchains
  • Built to last — stable APIs, permissive license, open development
